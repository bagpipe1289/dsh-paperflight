# 可选 DS 操作工具

preview.39 新增，默认全部关闭。在「设置 → 通用设置 → DS 操作工具」，或聊天右侧「终端 / 浏览器 → DS 操作」中启用。开关保存到当前 DSH profile 的外壳配置，影响该 profile 的所有会话。关闭后实际撤销注册，并取消该功能正在执行的操作；模型下一次获取工具清单时生效。已经发出的模型请求仍可能带有旧清单，此时调用会被拒绝。原有 DSH 或 MCP 工具不由这些开关控制。

## CMD

- 只增加 `mai_cmd` 一个工具。通过当前 Agent 可见的标准 DSH `pwsh` 工具执行 CMD，保留工具策略、会话工作目录与沙箱，不复用用户手动终端的进程或权限。
- Windows 专用，需要当前预设提供标准的非持久 PowerShell 工具；其他预设会明确报错，不走隐式替代通道。
- 每次调用需要 DSH 审批。命令在新的 CMD 进程执行，因此 `cd` 和环境变量不跨调用保留；目前仅支持单行命令，执行最多 30 秒，不提供交互式输入或后台作业。
- 右侧 DS 操作页显示执行状态、输出和停止按钮；手动操作页仍可使用原来的 CMD/PowerShell 终端。

## 浏览器

- 只增加 `mai_browser` 一个工具。一个入口提供打开、读取、点击、填写、按键、后退与关闭，不注册成多个独立工具。
- 需要机器上已安装 Microsoft Edge。插件依赖锁定 `playwright-core 1.63.0`；不自动下载浏览器，也不安装系统组件。安装插件时需要能获取此依赖。
- 每个 DSH 会话使用独立的临时无头浏览器。共享浏览器可由人或 DS 轮流操作同一个页面，切换不重建上下文；不会连接日常 Edge、Codex 浏览器或普通侧栏 iframe。关闭功能、结束会话所有者或停止宿主时关闭对应浏览器。
- 打开、点击、填写、按键与后退通过 DSH 审批；读取已打开网页、关闭浏览器不另行审批。第三方页面内容作为不可信资料返回给模型。
- 模型读取网页的可访问文本，按可访问角色和名称定位元素。共享浏览器的「我来操作」允许点击截图、滚动、输入文字与按键；截图在操作后更新，动态页面可手动同步。它不是实时视频。人接管时模型的读取、操作和关闭均被阻止；切回 DS 后需要重新读取页面。
- 不开放任意网页脚本、文件上传/下载和个人浏览器登录态。最多同时保持 4 个会话浏览器。浏览器访问网页会产生正常的网站网络请求，不能视作 DSH 文件沙箱内的进程；它通过独立上下文和逐项审批约束。

## 试用

1. 启用 CMD，在普通 DSH 预设下发送：「使用 mai_cmd 执行 echo DSH_CMD_OK」。在自动展开的审批弹窗核对并批准。确认聊天与 DS 操作页收到实际输出。
2. 启用浏览器，发送：「使用 mai_browser 打开 https://example.com，读出网页标题」。批准后检查侧栏截图和返回文字。继续测试目标站点的表单前，核对每项审批的操作内容。
3. 分别关闭开关，检查已注册扩展工具数量回到 0；原来的手动终端与手动浏览器应仍可使用。

安装包校验、隔离适配器测试与真实模型验收是三层不同证据。首次跨设备试用仍需核对 DSH 版本、预设、PowerShell、Edge 和审批通道。

## preview.42 接管与审批

- 审批和用户提问到达时自动弹出，可手动折叠；新请求到达时再次展开。右侧审核栏保留为查询入口。
- 「本会话相同操作不再询问」只匹配相同会话、工具、完整参数及申请原因，最多记住 100 条，保存在外壳进程内存中。会话顶部可撤销，重启外壳后清除。不是任意命令放行，也不改变宿主的沙箱或工具策略。
- 普通网页的「送到共享浏览器」在共享上下文重新打开网址；不会迁移 iframe 或个人 Edge 的 Cookie。共享页面内选择「我来操作／交给 DS」才是真正保留当前页面的接管。交给 DS 还会填入聊天草稿，用户发送后才开始模型请求。
- 可拖入 Edge 地址栏的网址或页面链接。能否直接拖动标签标题取决于 Edge 是否提供 URL 数据；不能把整个标签进程拖入网页。拖入共享区只填地址，点击打开后再选择交给 DS。
- DS 命令可以送到手动终端草稿，复制后自行执行；手动终端的选中内容或最近 60 行（最多 12000 字符）可以送到聊天草稿。两者不共享进程、目录和环境；手动终端的本机权限不会转给模型。发送前可删改草稿中的私人内容。


preview.43：共享页面通过 Edge 连续画面通道自动更新，面板可见时约每 200 ms 获取最新帧；这是远程画面，不是本机浏览器标签的原生渲染。画面传递不执行 read、不获取操作锁、不改变审批版本。操作按会话排队，接管后的操作重新核对控制者；打开网页等待文档响应后允许继续加载脚本。审批在会话上方原位展开。


preview.44：mai_browser 增加 wait（milliseconds 0–5000）、reload、scroll（delta -800–800），read 可传 role/name/index 局部读取，full:true 重复未变化正文。打开、点击等操作已返回快照，返回 changed/comparable、readiness、pendingRequests、warnings、diagnostics。等待最多 4 秒观察正文稳定及已知文档/XHR/fetch 完成；稳定不保证业务数据已加载。诊断仅保留最近 10 个失败请求路径/HTTP 状态和脚本异常标记，不收集请求正文、认证头或完整控制台。修改操作继续交由宿主审批；结果无法区分人工批准与自动规则。wait 只等待，不替代或跳过审批。截图仍在人类侧栏可见，尚未传给模型；控件引用 ref 和任意选择器未开放。
