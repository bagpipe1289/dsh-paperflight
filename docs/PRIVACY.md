# 纸航 Paperflight 数据处理说明（预览版）

日期：2026-10-09。对象是纸航 Paperflight（原 DSH Mai Shell），而非 MaiBot 聊天机器人；正式发布前还需针对发布版本做网络和行为核验。

| 数据/行为 | 当前处理方式 |
| --- | --- |
| 账号、模型和会话 | 通过当前 DSH 宿主的接口访问；原有凭据由宿主管理，外壳不是独立账号服务 |
| 外壳鉴权 | 宿主向子进程传递运行参数；本机入口换取浏览器 HttpOnly Cookie；不把原账号凭据当作网页展示内容 |
| 账号累计消费 | 在宿主内请求 DeepSeek 官方账户摘要，只将金额、币种及状态投影给外壳；余额不冒充累计消费 |
| 会话、文件、终端、插件操作 | 外壳可依用户操作调用宿主能力，可能读写本地文件、执行命令或访问网络；效果由宿主和已启用插件共同决定 |
| 外壳自己的数据 | 工作目录默认值、部分偏好/分组与备份等存入 DSH_HOME/mai-shell/<profile>；不是本源码目录里的样例数据 |
| 浏览器本地存储 | 主题、字号、侧栏等偏好保存在浏览器存储中；不同 origin 分开保存 |
| 可选模型工具 | preview.39 的 CMD / 浏览器开关默认关闭，状态保存到外壳运行目录 agent-tools.json。开启后由模型调用，经 DSH 审批执行操作 |
| 模型工具记录 | 每会话最近 20 条工具状态/输出保存在宿主进程内存中，最多保留 100 个会话；会话所有者销毁或插件停止时清除。命令、网页文本和审批还可能进入 DSH 原有会话日志，由宿主管理 |
| DS 浏览器 | 使用各会话独立的临时 Edge 上下文，访问用户批准的网站；不读取个人浏览器配置。最近操作截图在本机内存中供侧栏显示，网页可访问文本会返回模型。关闭该浏览器即清除其上下文和截图，不等于删除宿主已经记录的工具结果 |
| 外部连接 | 账户服务会联系 platform.deepseek.com；版本检查使用 GitHub；插件市场及安装使用所配置的市场/下载源；用户打开的网页及模型请求按用户操作访问相应服务 |
| 第三方前端资源 | Iconify 未内置的图标可能触发远程获取；语音、网页和其他组件的实际网络行为仍需发布前动态核验 |
| 日志与卸载 | 宿主日志、外壳备份和浏览器存储可能在卸载后保留；卸载不等于清除全部历史数据 |

本地构建源码包不需要用户账号，白名单打包排除运行目录、会话、凭据、日志和 node_modules。本轮不会声称已完成全面隐私审计，也不会借用 MaiBot 原隐私政策来覆盖本项目行为。

公开发布前应在界面提供本说明、项目来源、许可证与对应源码入口；补齐实际服务提供方/联系方式、日志保留与删除说明。不要未经说明添加遥测或把本机文件发送到与用户操作无关的服务。

## 保留与删除

preview.42：共享浏览器的人机接管保留同一临时上下文，因此人在共享页面中登录后，交回 DS 会使模型能够操作该登录状态下的页面。不会导入个人 Edge 的 Cookie。手动输入通过本机鉴权接口送到该页面；输入内容不写入本插件操作记录，但目标网站会收到对应输入，模型之后读取的页面及宿主工具日志也可能包含页面内容。终端「输出交给 DS」与浏览器「交给 DS」只生成聊天草稿，由用户核对并发送。相同操作审批规则仅存于外壳内存，使用会话、工具、完整参数及申请原因的哈希匹配，可在会话顶部清除；外壳重启后失效。

本外壳不设置统一自动过期时间。宿主的会话/账户/插件数据由 DSH 管理；请在原生对应界面删除或退出账号。外壳文件位于 DSH_HOME/mai-shell/<profile>（默认 DSH_HOME 为用户主目录下 .dsh）：停止外壳后先备份需要保留的内容，再移除该 profile 外壳目录；这不删除宿主会话。清除浏览器对实际 127.0.0.1 端口的站点数据可删除外观偏好、自定义头像、分组等浏览器数据，亦会失去本浏览器登录态。不要清空整个 DSH_HOME。日志和备份不会因卸载自动消失。

## 维护与反馈

维护账号：bagpipe1289；联系入口：https://github.com/bagpipe1289/dsh-paperflight/issues 。此版本没有项目方运营的独立云端账户服务；GitHub 下载/问题反馈、DeepSeek 模型与第三方插件分别适用各自说明。不要在 Issues 中上传账号密钥、完整聊天、未脱敏日志或私人文件。公开发行仅包含项目源码、构建产物和许可资料，不包含本机运行数据。

设置页的「许可、隐私与本版本源码」在本机展示本说明并提供源码下载，不需第三方登录。标签图标只从当前已连接的本机 DSH 获取；仓库和安装包不含该图标。

preview.49：官方 Playwright MCP 在进程内复用隔离浏览器，不连接云端浏览器服务。MCP 临时诊断文件正常关闭后清理，异常退出可能残留在系统临时目录 paperflight-mcp-*；截图仅在显式 screenshot 且宿主确认模型支持图片时写入宿主附件存储。已记住授权只保存在服务内存，右栏支持逐项撤销。

preview.51：浏览器会把当前页有限数量的控制台警告、错误和网络失败详情作为诊断返回模型，并可能进入宿主工具日志。每条文本最多 1,000 字符；移除网址查询参数、遮盖常见凭据字段，但无法保证网站自行打印的任意正文不含敏感信息。不会读取控制台对象参数。页面正文分段返回，续读描述只保存摘要、位置和范围；关闭浏览器后清除，已返回的正文仍按宿主会话保留策略处理。


preview.52：首页默认从 https://v1.hitokoto.cn/ 获取一句名句，不发送 DSH 账号、Cookie、聊天内容或页面来源；该服务仍会收到网络请求的 IP 等通常连接信息。可在一言编辑器关闭默认来源，仅保留自定义内容，关闭后不请求该服务。网络失败使用内置名句。

浏览器 upload 会把审批中指定的工作区文件交给当前网页，网站可能在选择后立即上传；应核对文件和网站。download 先使用系统临时目录 paperflight-download-*，完成后写入会话工作区 browser-downloads，关闭浏览器时清理临时目录，异常退出可能留下临时文件。工作区下载文件不会因关闭浏览器删除，可在确认不需要后自行删除。传输路径、大小、校验值和结果可进入宿主日志；不自动打开或执行文件。
