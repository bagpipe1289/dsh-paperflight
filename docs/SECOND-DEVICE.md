# 另一台 Windows 电脑：纸航预览版安装与测试

版本：0.1.0-preview.48。先测试 DSH Web 版；纸航尚未验证官方桌面版。此前宿主基线为 DSH 0.2.0-rc.2，其他版本请记录实际版本，不假定兼容。

## 准备

1. 使用官方来源安装 DSH Web 运行环境，先打开原生界面并完成一次简短聊天。已有 DSH 的电脑不必重新安装；先记录版本。
2. 从 https://github.com/bagpipe1289/dsh-paperflight/releases/tag/v0.1.0-preview.48 下载插件 `dsh-paperflight-0.1.0-preview.48.tgz` 和 `SHA256SUMS.txt`。带 `source` 的包是对应源码，不是插件。
3. 保留原环境，使用空工作区和测试会话。不要复制另一台电脑的整个 `.dsh`、登录缓存、模型密钥或聊天数据库。
4. 浏览器工具测试需要本机 Microsoft Edge。工具开关默认关闭，安装纸航不会自动导入你的个人 Edge 登录态。

## 安装

如果当前配置安装过旧包 `dsh-mai-shell`（preview.47 及以前），先结束正在运行的会话和工具操作，在原生插件管理中卸载旧包，再安装本版。只停用旧包不足以完成包名迁移；不要同时安装或启用两个包。不要删除 `.dsh/mai-shell/`，它保留工作区和偏好。原包的自定义端口等实例配置请先记录；新包安装后按原值设置。迁移与回退细节见[命名与迁移](https://github.com/bagpipe1289/dsh-paperflight/blob/main/docs/NAMING.md)。

原生「添加插件」输入框也接受本版安装包的 HTTPS 直链（不是仓库首页，也不是 npm 自定义源）：

```text
https://github.com/bagpipe1289/dsh-paperflight/releases/download/v0.1.0-preview.48/dsh-paperflight-0.1.0-preview.48.tgz
```

保留默认安装源即可。网络超时时先下载 tgz，再按下方本地路径安装；在线下载与新设备安装仍需实际验收。

优先在 DSH 原生插件管理中添加本地 tgz；若没有这个入口，打开该 DSH 环境自带的终端，先运行 `dsh --version`，确认对应正在使用的宿主。

假设包保存到 `D:/DSH-Plugins/Paperflight/`：

```powershell
dsh plugin --profile web add "file:D:/DSH-Plugins/Paperflight/dsh-paperflight-0.1.0-preview.48.tgz"
```

这里使用完整路径，因此 PowerShell 在哪个目录打开都可以，不必特意 cd。将示例路径换成实际路径；`web` 必须是你正在使用的配置。若找不到 dsh 命令，使用管理器提供的终端，不要另装一个全局 DSH 去修改错误环境。

按原生提示刷新或重启空闲的 DSH，打开设置中的「纸航 Paperflight」。从原生入口进入以建立登录态，不要直接照抄 3182 端口。确认插件版本是 preview.48。出现安装错误先保留报错，尤其不要删除正式配置、锁文件或全部用户数据。

## 第一轮：核心检查

| 操作 | 通过标准 | 结果 |
| --- | --- | --- |
| 打开与刷新 | 首页、会话可进入；刷新不反复跳登录；名称显示纸航 | 待测 |
| 会话 | 新建、发送短消息、切换、重命名、归档恢复正常 | 待测 |
| 分组与排序 | 整行拖动排序和移入分组后，刷新仍保留 | 待测 |
| 文件 | 上传写有 PAPERFLIGHT-TEST 的 txt，让模型读出标记；点生成文件链接打开右侧预览 | 待测 |
| 审批 | 开启 CMD 工具，让 DS 运行 `echo PAPERFLIGHT-TEST`；审批在会话顶部展开，批准后结果正确 | 待测 |
| 共享浏览器 | 开启工具，打开普通测试页；你和 DS 轮流控制，返回可读内容；关闭开关后工具撤销 | 待测 |
| 弹窗与滚动 | 打开设置/下拉选项，页面不横向跳动；关闭弹窗后可继续滚动 | 待测 |
| 连接恢复 | 正常使用中刷新、切换会话；记录任何持续断连或外壳退出 | 待测 |
| 许可与源码 | 设置中打开隐私/许可并下载同版源码 | 待测 |
| 停用与卸载 | 空闲时停用纸航，原生仍可用；重新启用正常；卸载保留原 DSH 会话 | 待测 |

CMD/浏览器工具分别开关，首次按实际审批操作；不要用真实账号付款、发送消息或敏感文件做测试。附件是否选中不算成功，要确认模型读出了文件内容。

其他插件面板（技能、任务、记忆）可在核心检查通过后分别安装验证；纸航不捆绑这些插件。缺少插件时入口隐藏是预期行为。
