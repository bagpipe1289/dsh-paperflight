# 浏览器适配与验证（preview.52）

## 选择

采用微软官方 [Playwright MCP](https://github.com/microsoft/playwright-mcp) 0.0.83，Apache-2.0。其 npm 依赖固定 Playwright 1.64.0-alpha-1790635538000；纸航使用同一版本，避免对象协议不一致。固定版本不代表所有网站都已验证。

2026-10-09 查询 [npm 下载统计](https://api.npmjs.org/downloads/point/last-week/@playwright/mcp)：2026-10-01 至 2026-10-07 共 6,678,981 次下载。GitHub 页面约 38k stars；下载量包含自动化安装，不能代替质量验收。

对比了 [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) 与 [Stagehand](https://github.com/browserbase/stagehand)。纸航已有 Playwright 页面、Edge 上下文及连续画面；官方 MCP 的程序化 createConnection(config, contextGetter) 可以复用同一上下文，因此接入成本更低。没有为了浏览器再引入另一套模型规划器、云浏览器账号或独立 MCP 工具清单。

## 接入范围

- 仍只有 mai_browser 一个模型工具，开关和宿主审批保留。
- MCP 在插件进程内通过内存 JSON-RPC 工作，没有新增对外监听端口。公开适配仅允许调用 snapshot、click、type 和 tabs；不向模型开放任意脚本或网页声明的 WebMCP 工具。preview.52 的文件传输由纸航的工作区校验与审批单独管理；内部用不带文件参数的 browser_file_upload 清理 MCP 文件选择器状态，实际文件经校验后以字节传给同一页面。
- 引用 ref 来自最近一次页面快照，解决部分无角色名称的交互元素。复杂 Canvas、封闭组件等仍可能无法定位。
- 新窗口保留，点击后跟随弹出的标签；支持 tabs/select，右侧手动模式也可切换标签，最多 8 个标签。
- 原有 CDP 连续画面继续展示当前标签。MCP 本身不是实时视频服务；图像来自同一个隔离 Edge 页面。
- screenshot 显式请求截图，通过宿主附件服务提供给声明支持图像输入的当前模型；无法核实视觉能力时返回 vision.delivered=false，不把 base64 当正文塞入模型。纯文本模型不会因安装 MCP 获得视觉能力。
- MCP 临时诊断输出保存在系统临时目录 paperflight-mcp-*，正常关闭后删除；进程崩溃时可能残留，不包含在发行包中。浏览器操作与截图可进入宿主的会话记录，按宿主的数据保留策略处理。

## 验收边界

本地真实 Edge 的可控测试页覆盖：非语义 div 点击、新标签跟随、切回原标签、截图捕获、手动/DS 接管、连续画面。权限与模型图片通道有独立回归。它不等于百家号等真实站点全量兼容，也不等于真实 DSH 模型已成功理解图片；这两项需要安装候选包后继续验收。

## preview.51 长页读取与诊断

- 单次正文最多约 14,000 字符，优先沿行边界切分。`pagination.hasMore` 和 `nextCursor` 表示可续读；调用 `read` 并仅传 `cursor`。重新获取内容并核对摘要，发生变化则要求重新读取或缩小章节。游标不跟随视口滚动；它不是完整页面的长期缓存。
- `read heading:"评分规则"` 读取精确可见标题到下一同级或更高标题之前的正文，包括子标题。重复标题用 `index`。不把标题文本虚构为 generic 的名称。
- `read format:"text"` 返回正文文字，减轻公式造成的无障碍树膨胀；不会生成可点击引用，也不保证保留数学公式的二维结构。需要结构时使用默认无障碍树、`read ref` 或显式截图。
- `contentChanged` 描述同范围正文变化；`scroll.moved` 与滚动前后位置描述窗口和最多 50 个已滚动容器的变化。不能把正文不变理解为滚动失败。
- `documentReady`、`contentStable`、`pendingRequests` 独立报告。后台请求不阻止正文稳定；稳定也不证明业务数据完整。
- `diagnostics` 保留最近最多 10 条本站/未知来源及 5 条第三方消息，含来源分类。控制台只取警告和错误的文本，不读取对象参数；每条最多 1,000 字符，移除网址查询参数并遮盖常见凭据字段。任意日志仍可能包含敏感正文，不能视为全面脱敏。
- 隔离 Edge + 官方 MCP 实测：约 17 万字符的公式长页分 13 段读取到尾部，标题边界、正文读取、ref 区域、滚动、后台请求与控制台详情均通过；点击/填表/弹出标签/共享接管仍可用。此为受控页面验证，未访问用户比赛页面或替代 DSH 模型测试。


## preview.52 文件传输

先点击观察到的上传按钮，返回 fileChooserPending 后调用 upload 并给出工作区文件 path；也可对已观察的文件输入 ref 直接 upload。宿主 fs 服务执行受限二进制读取；审批前仅查询元数据，审批后再次核对文件版本。选择文件不等于网站已接收成功，需要核对网站回执。

download 要求观察到的链接或按钮 ref / role + name，等待下载并检查大小后保存到工作区 browser-downloads，文件名添加随机前缀，返回 transfer.path / relativePath / bytes / sha256。只读会话拒绝下载；不提供扩大沙箱或自动执行下载内容的路径。宿主当前没有二进制写入接口，因此仅支持能映射到本机且明确允许写入的会话工作区，按宿主策略和真实路径检查保存，不支持远程文件提供者。下载上限 50 MiB、开始等待 15 秒、传输等待 60 秒；临时目录大小轮询会存在短时超出上限的可能。

文件传输不复用记忆授权。普通点击或后台触发的下载会取消，需用 download 明确重试；手动侧栏本次仍负责查看与接管，文件传输通过 DS 工具执行。右侧工具结果提供下载文件的查看入口。

本版隔离 Edge + 官方 MCP 验证了 PDF 上传、ZIP 与同源 Blob 下载的实际字节、重复下载不覆盖、51 MiB 文件拒绝、普通点击下载取消。测试使用模拟宿主文件服务；真实 DSH 模型调用与首页视觉验收未完成，不能据此宣称所有网站或正式环境已通过。
